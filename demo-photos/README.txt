FolderFrame Curated Stock Collection
====================================

140 attributed, web-optimized photographs: 65 landscapes, 35 architecture, and 40 space images.
Each attributed image appears once in the demo tree, producing 140 file placements across the nested album structure.
Images are 1600px or less on the long edge and saved as progressive JPEGs.

LICENSING
Each image remains subject to the license listed in ATTRIBUTION.csv. Keep that file with the collection and provide attribution where its listed license requires it. The Commons page is the authoritative source record for each photograph.

This collection is intended for FolderFrame website screenshots and live demos. It should not be redistributed as a standalone stock-photo product.
