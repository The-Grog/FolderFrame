# FolderFrame branding

Use the supplied artwork; do not recreate the logo or wordmark.

- **FolderFrame Title Logo.png**: website, app and GitHub headers.
- **FolderFrame Icon.png**: round icons and icon buttons; source for favicons.
- **FolderFrame Logo.png**: standalone folder-in-frame mark.
- Brand lettering uses **Rhodium Libre**. Keep normal UI text in the existing UI font.

Preserve aspect ratio. The title has white lettering: use it on dark backgrounds. The GitHub light-theme derivative has a dark backing for legibility. Originals in this directory are unchanged; optimized copies live in docs/images.

Screenshots are historical captures and should be replaced with fresh captures when the UI is next photographed, not retouched.
